# 统一填充覆盖逻辑与侧栏/Popup 通道

- [ ] 新功能

## 变更内容

### 1. 全量覆盖填充（engine.ts）

**状态**：`targetHasValue()` 跳过逻辑 → 全量覆盖

**文件**：`entrypoints/content/engine.ts`

**改动**：在 `fillPass()` 中移除了 `targetHasValue()` 检查块，该检查导致已有值的字段被跳过而非覆盖。现在每次点击"自动填充"都会覆盖所有字段。

**原因**：用户期望覆盖操作，而非跳过已有值字段。不需要额外提示。

### 2. 侧栏 AutofillTab 与 Popup 统一（Widget.tsx）

**文件**：`entrypoints/content/Widget.tsx`

**改动**：
- 移除 `AutofillReviewItem` 类型引用（不再需要）
- 添加 `FillResult` 类型导入
- 重写 `AutofillTab` 组件：与 Popup 使用相同的状态展示逻辑（填充率、已填充/跳过/无数据/未匹配计数）
- 增加"预览填充"按钮，与 Popup 保持一致
- 移除独立的 review list 展示（浮动通知条已处理详情）

**原因**：侧栏和 Popup 是两个入口，进入后应提供相同的功能和 UI。底层填充引擎相同（`fillCurrentForm()`），浮动通知条（`injectFillNotification()`）由内容脚本消息处理器统一注入。

### 架构变化

```
改动前:
  Popup → AUTOFILL_ACTIVE_TAB → background → AUTOFILL_CURRENT_FORM → fillCurrentForm() → 浮动通知条
  Widget → AUTOFILL_TAB → background → AUTOFILL_CURRENT_FORM → fillCurrentForm() → 浮动通知条 + 独立 review list

改动后:
  Popup → AUTOFILL_ACTIVE_TAB → background → AUTOFILL_CURRENT_FORM → fillCurrentForm() → 浮动通知条
  Widget → AUTOFILL_TAB → background → AUTOFILL_CURRENT_FORM → fillCurrentForm() → 浮动通知条
  （两者展示相同的状态文本格式，无独立 review list）
```
