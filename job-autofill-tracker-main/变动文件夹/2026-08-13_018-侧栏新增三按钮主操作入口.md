## 需求说明

用户希望将侧边栏（Widget）的操作入口优化为顶部 3 个主按钮：**填充、预览、进入控制台**。
- 「填充」：与原本一致，点击识别当前页面并自动填充（`AUTOFILL_TAB`）。
- 「预览」：与原本一致，先预览再确认填充（`PREVIEW_FILL`）。
- 「进入控制台」：跳转到扩展仪表盘（Options 页面，`OPEN_DASHBOARD`）。

功能逻辑不变，仅做 UI 入口优化。三个按钮复用 Widget 内已有的 `doAction("AUTOFILL_TAB")`、`doPreview()`、`openDashboard()` 处理器，不新增消息类型、不改动 background。

经与用户确认：**顶部 3 按钮 + 下方保留现有 Tabs**（匹配/自动填表/答案/Upwork/跟踪器/资料）。Tabs 及其面板功能不变。

## 设计决策

1. **3 按钮置于 drawer 顶部**（header + demo 徽章之下、`drawer-state` 之上），作为最显眼的主操作入口。
2. **移除 scored 状态卡片内重复的填充/预览按钮**：原本在职位详情页匹配成功时，`drawer-state` 卡片里内嵌了「填充 / 预览」两个按钮。顶部 3 按钮出现后，同一动作在两处出现会造成混淆，故移除卡片内的这两个按钮，仅保留匹配分数展示。
3. **保留 footer 的「打开仪表盘」按钮**：footer 的仪表盘按钮属于跟踪流程的上下文操作（与「跟踪此职位」并排），与顶部「进入控制台」主入口定位不同，保持不动以最小化改动。
4. **新增 3 个 i18n key**：遵循项目「所有用户可见文案集中在 `lib/i18n.ts`」的约定，使用短标签「填充/预览/进入控制台」匹配用户措辞，而非复用较长的 `popup.autofill` 等。
5. **样式复用**：3 按钮复用现有 `.jtButton` / `.jtButtonGhost` 类，仅新增 `.jtPrimaryActions` 网格容器样式，与现有设计 token 一致。

## 修改文件

### 修改：`entrypoints/content/Widget.tsx`
| 状态 | 说明 |
|------|------|
| 原状态 | 侧栏打开后直接进入 `drawer-state`（状态卡片）+ Tabs + footer，无统一的主操作按钮入口；填充/预览按钮仅在 scored 状态卡片内出现 |
| 操作 | 1) 在 `<>` 片段开头（`drawer-state` 之前）新增 `.jtPrimaryActions` 容器，含 3 个按钮：填充(`doAction("AUTOFILL_TAB")`)、预览(`doPreview()`)、进入控制台(`openDashboard()`)，均 `disabled={actionBusy}`；2) 从 scored 状态卡片中移除内嵌的填充/预览按钮，仅保留分数与「匹配分数」标签 |
| 当前状态 | 侧栏顶部有 3 个始终可见的主操作按钮，下方 Tabs 与 footer 不变 |

### 修改：`lib/i18n.ts`
| 状态 | 说明 |
|------|------|
| 原状态 | 无 `widget.primaryFill` / `widget.primaryPreview` / `widget.primaryDashboard` |
| 操作 | 在 Widget 区块新增 3 个 key：`widget.primaryFill`(填充/Fill)、`widget.primaryPreview`(预览/Preview)、`widget.primaryDashboard`(进入控制台/Open Console) |
| 当前状态 | 3 个主按钮文案走 i18n，中英双语可用 |

### 修改：`entrypoints/content/widget.css`
| 状态 | 说明 |
|------|------|
| 原状态 | 无 `.jtPrimaryActions` 样式 |
| 操作 | 新增 `.jtPrimaryActions` 样式：3 列等宽网格、横向 padding 与 drawer 一致、底部加分割线；其内 `.jtButton` 设为 100% 宽度并增大纵向 padding |
| 当前状态 | 3 按钮在侧栏顶部等宽排列，视觉与既有按钮体系一致 |

## 布局变化

```
改动前:
  Header → DemoBadge → [pendingConfirm 或:
    drawer-state(含 scored 卡片内嵌 填充/预览 按钮) → drawer-nav(Tabs) → jtDrawerBody → footer]

改动后:
  Header → DemoBadge → [pendingConfirm 或:
    jtPrimaryActions(填充/预览/进入控制台) → drawer-state(scored 卡片仅显示分数) → drawer-nav(Tabs) → jtDrawerBody → footer]
```
