# 2026-08-07 创建离线测试页面

## 需求

创建一个本地可运行的测试页面，模拟中文求职申请表，用于验证扩展的自动填充功能（特别是中文字段映射字典）是否正常工作。无需联网，纯前端可测。

## 变动状态机

| 阶段 | 状态 |
|------|------|
| 原始 | 无离线测试手段，只能访问真实求职网站验证 |
| 操作 | 创建 `test/test-form.html` 测试页面 |
| 当前 | 通过 `npx serve test -l 8080` 可本地启动模拟申请表，覆盖 5 类测试场景 |

## 变更文件

### 新增

- `test/test-form.html` — 离线测试页面。包含 21 个表单字段，覆盖：
  - 个人信息：姓、名字、电子邮箱、手机号码、所在城市、省份、国家/地区（7 个）
  - 工作信息：当前公司、当前职位、期望薪资、币种、信息来源（5 个）
  - 资格信息：英语水平、美国工作授权、是否需要签证担保（3 个）
  - 人口统计：性别、种族、退伍军人、残疾状态（4 个）
  - 法律确认：2 个 checkbox（永不自动填充）
  - 页面包含"提交申请"关键词，可触发扩展的 `hasApplicationSurface()` 门禁
  - 自动监听 input 事件，填充后实时显示填充结果

### 修改

- `使用手册.md` — 目录新增第 13 节"离线测试"，含启动命令、测试目标和测试用例对照表。

## 验证

- 页面在 Chrome/Edge 中可正常渲染
- 通过 `npx serve test -l 8080` 启动后，扩展 Content Script 可注入（HTTP 协议）
- 测试方式：注入简历 → 打开测试页 → 点击"自动填充当前页面" → 观察填充结果
