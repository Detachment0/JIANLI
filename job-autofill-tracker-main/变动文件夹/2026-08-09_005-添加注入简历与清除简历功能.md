# 添加注入简历与清除简历功能

## 时间
2026-08-07

## 需求说明

用户希望：
1. 将自己的简历文本作为实例数据，先逐字段映射到扩展的 Profile 数据结构中
2. 在 Popup 上添加"注入简历"按钮，点击后简历数据注入浏览器 `chrome.storage.local` 待用
3. 在 Popup 上添加"清除简历"按钮，点击后清空已注入的简历数据
4. 下次注入时，如果不清除旧数据直接注入，会覆盖为新数据

## 修改文件

### 新增：`lib/resumeData.ts`
| 状态 | 说明 |
|------|------|
| 原状态 | 不存在 |
| 操作 | 创建，导出 `RESUME_PROFILE` 常量，包含完整的 Profile 结构 |
| 当前状态 | 已创建，包含用户的简历数据映射 |

### 修改：`lib/schema.ts`
| 状态 | 说明 |
|------|------|
| 原状态 | 无 `INJECT_RESUME_PROFILE` 和 `CLEAR_RESUME_PROFILE` 消息类型 |
| 操作 | 添加两个新消息类型，并入 `ExtensionMessage` 联合类型 |
| 当前状态 | 支持两种新消息的发送和处理 |

### 修改：`entrypoints/background.ts`
| 状态 | 说明 |
|------|------|
| 原状态 | 无简历注入/清除处理逻辑 |
| 操作 | 在 `handleMessage` 中增加 `INJECT_RESUME_PROFILE`（写入 profile 到 storage）和 `CLEAR_RESUME_PROFILE`（删除 profile 键） |
| 当前状态 | 后台正确处理注入和清除请求 |

### 修改：`entrypoints/popup/main.tsx`
| 状态 | 说明 |
|------|------|
| 原状态 | 仅有三个按钮（自动填充、打开侧面板、跟踪仪表盘） |
| 操作 | 增加"注入简历"和"清除简历"两个按钮，下方显示分割线，点击后发送对应消息 |
| 当前状态 | Popup 分为两组：核心功能 + 简历管理 |

### 修改：`entrypoints/popup/styles.css`
| 状态 | 说明 |
|------|------|
| 原状态 | 无 `.resume-actions` 样式 |
| 操作 | 增加 `.resume-actions` 样式，含顶部边框分隔线 |
| 当前状态 | 简历管理按钮与核心功能按钮视觉分隔 |

## 判断无需更新架构文档的原因
本次修改不涉及架构边界、模块职责、业务链路、消息协议（新增的消息类型已注册到 schema.ts 的联合类型中，属于类型扩展）、数据结构、全局不变量或运行方式。仅新增了两个独立的功能按钮，数据流为直接读写 chrome.storage.local，不改变既有交互链路。
