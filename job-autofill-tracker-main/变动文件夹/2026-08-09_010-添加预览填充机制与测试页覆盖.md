# 2026-08-07 添加预览填充机制与测试页覆盖

## 需求

1. 填充前先预览，让用户确认后再执行，避免盲目填充
2. 测试页增加覆盖所有填充状态的字段

## 变动状态机

| 阶段 | 状态 |
|------|------|
| 原始 | 只有"自动填充当前页面"一键填充，无预览机制 |
| 操作 | 新增 `PREVIEW_FILL` 消息类型 + `dryRun` 模式 + 预览弹窗 + 确认流程 |
| 当前 | Popup 中有"预览填充"按钮 → 预览弹窗展示 → 确认/取消 → 实际填充 |

## 变更文件

### 修改

- `lib/schema.ts` — 新增 `PreviewFillRequest` 类型和 `PREVIEW_FILL` 消息
- `entrypoints/content/engine.ts` — 
  - `fillCurrentForm()` 新增 `dryRun` 参数（默认 false）
  - `dryRun=true` 时跳过 `applyFill()` 调用，只收集预览数据
  - `fillPass()` 新增 `dryRun` 参数传递
- `entrypoints/content/index.tsx` —
  - 新增 `PREVIEW_FILL` 消息处理器
  - 新增 `injectPreviewModal()` 函数：注入居中弹窗，展示预览数据 + 确认/取消按钮
  - 确认按钮调用 `fillCurrentForm(false)` 执行实际填充
- `entrypoints/background.ts` — 新增 `PREVIEW_FILL` 消息路由
- `entrypoints/popup/main.tsx` —
  - 新增 `previewFill()` 函数
  - 新增"预览填充"按钮（`Eye` 图标）
- `test/test-form.html` — 新增"覆盖测试"区块，包含：
  - 自定义字段（预期：no_match）
  - LinkedIn 主页（预期：no_data）
  - 签证状态（预期：no_data）
  - 性别（预期：no_data）
  - 种族（预期：no_data）
  - 自定义组件（预期：custom_component）
  - 法律确认（预期：skipped）
- `使用手册.md` — 新增第 15 节"预览填充"

## 覆盖测试字段

| 字段 | 预期填充状态 | 验证方式 |
|------|-------------|----------|
| 自定义字段 | ❓ no_match | 无字典映射 |
| LinkedIn 主页 | ➖ no_data | 匹配 canonical 但无数据 |
| 签证状态 | ➖ no_data | 匹配 canonical 但无数据 |
| 性别 | ➖ no_data | 匹配 canonical 但无数据 |
| 种族 | ➖ no_data | 匹配 canonical 但无数据 |
| 自定义组件 (div contenteditable) | ✋ custom_component | 非标准 input |
| 法律确认 checkbox | ⊘ skipped | 法律确认字段 |
