# 同义词字典增加开关 toggle 和全名 field

## 变更类型
- [x] 功能修改
- [x] 数据结构变更

## 变更内容

### 1. 新增 `identity.fullName` 规范字段

**文件**：`lib/schema.ts`
- `CanonicalField` 增加 `"identity.fullName"`
- `Profile.identity` 增加 `fullName: string`
- `EMPTY_PROFILE` 增加 `fullName: ""`

**填充逻辑**（`lib/mapping.ts`）：
- `getProfileValue` 中 `identity.fullName` 返回 `firstName + " " + lastName` 的组合值

### 2. 字典条目增加 `enabled` 开关

**文件**：`lib/schema.ts`
- `CustomSynonymEntry` 增加 `enabled: boolean` 字段

**文件**：`lib/customSynonyms.ts`
- 所有 39 个默认条目均添加 `enabled: true`
- 新增 `cs-fullname` 条目（`identity.fullName`），同义词包含"姓名"、"全名"、"full name"等
- `cs-name`（`identity.firstName`）移除了"姓名"、"中文姓名"等全称类同义词，避免与 `cs-fullname` 冲突

**文件**：`lib/mapping.ts`
- `deterministicValue()` 构建字典时跳过 `enabled === false` 的条目

### 3. UI 删除按钮 → 开关 toggle

**文件**：`entrypoints/options/main.tsx`
- 删除按钮（X 图标）替换为开关 toggle 控件
- `addSynonym()` 新增条目默认 `enabled: true`
- `FIELD_LABELS` 增加 `"identity.fullName": "姓名（全称）"`
- 表头增加"开关"列

**文件**：`entrypoints/options/styles.css`
- 新增 `.synonymToggle`、`.synonymToggleSlider` 样式（32x18px 滑块开关）
- 支持 dark mode

### 4. 数据填充

**文件**：`lib/resumeData.ts`
- `fullName: "猫猫头 猫头鹰"`

**文件**：`lib/demo.ts`
- `fullName: "Maya Chen"`
