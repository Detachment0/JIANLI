### 1 段经验 vs 3 段预期

- profile 中有 3 段工作经历（美团/用友/大平移）
- 测试表单默认只显示第 1 段工作经历输入框
- 预期填充结果：第 1 段填满，第 2-3 段 **无对应的输入框** → 状态为 `partial`（部分填充）
- 用户需手动点击"添加工作经历"按钮新增输入框后，再次填充

## 填充状态覆盖

测试表单末尾的 `data-test="coverage"` 区块专门用于验证 7 种填充状态：

| 状态 | 触发条件 | 测试字段 | 验证方式 |
|------|----------|----------|----------|
| no_match | 字段标签无字典映射 | `customField` | 通知标记"未匹配" |
| no_data | 映射到 canonical 但 profile 无数据 | `linkedin`, `visaStatus`, `gender`, `race` | 通知标记"无数据" |
| custom_component | 非标准 input/select/textarea | `div[contenteditable]` | 通知标记"需手动操作" |
| skipped | 法律确认字段 | `legalConfirm` checkbox | 通知标记"已跳过" |
| filled | 全匹配成功 | 大多数有数据的字段 | 通知标记"已填充" |
| partial | 多段数据仅填了部分 | 工作经历第 1 段填满，第 2-3 段无框 | 通知标记"部分填充" |
| fill_error | 填充过程异常 | （需模拟异常场景） | 通知标记"填充异常" |

## 字段映射速查

测试表单中带 `.hint` 提示的字段，标注了其与 canonical field 的关联：

| 表单标签 | hint 文本 | 映射到的 canonical field |
|----------|-----------|-------------------------|
| 手机号 | 手机号 | identity.phone |
| 国家/地区区号 | — | identity.phoneCountryCode |
| 常用邮箱 | 电子邮箱 | identity.email |
| 中文姓名 | 姓名 | identity.firstName + identity.lastName |
| 姓 (Last Name) | 姓 | identity.lastName |
| 现居城市 | 所在城市 | identity.location.city |
| 详细地址 | 地址 | identity.address |
| 国籍 | 国家/国籍 | identity.location.country |
| 当前薪资 | 当前薪资 | applicationDefaults.currentSalary |
| 期望薪资 | 期望薪资 | applicationDefaults.desiredSalary |
| 薪资币种 | 币种 | applicationDefaults.salaryCurrency |
| 是否具有当地合法工作资格 | 美国工作授权 | workAuthorization.usAuthorized |

| 熟练程度 / 英语水平 | 英语水平 | workAuthorization.englishProficiency |
