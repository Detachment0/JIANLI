# 2026-08-07 添加中文字段映射字典

## 需求

在配置台（仪表盘设置页）增加一个可配置的中文字段映射字典，用于自动填充时识别中文网站上的表单字段标签。字典为多对一关系，例如"实践经历""实习""过往实习"都映射到"实习经历"（规范词）。用户可手动增删改字典条目。

## 变动状态机

| 阶段 | 状态 |
|------|------|
| 原始 | 引擎仅支持英文关键词匹配；英文求职网站可用，中文网站（如滴滴招聘）门禁不放行、字段匹配不上 |
| 操作 | 见下方"变更文件"逐项 |
| 当前 | 引擎支持中英文关键词匹配；设置页可管理自定义字典；字典存在 `chrome.storage.local` 中持久化 |

## 变更文件

### 新增

- `lib/customSynonyms.ts` — 自定义同义词存储层。默认种子数据包含 19 个常见中文字段映射（姓名、邮箱、电话、公司、职位等）。提供 `loadCustomSynonyms()`、`saveCustomSynonyms()` 两个函数。

### 修改

- `lib/schema.ts` — 新增 `CustomSynonymEntry` 类型（`{ id, field, synonyms }`）。
- `lib/synonyms.ts` — 所有 36 个 `CanonicalField` 条目均添加了中文同义词，覆盖姓名、邮箱、电话、地址、城市、公司、职位、薪资、签证、性别、种族、退伍军人、残疾等常见字段。
- `lib/mapping.ts` — `normalizeText()` 正则改为保留中文字符（`\u4e00-\u9fff`）。`deterministicValue()` 改为 `async`，先查内置 SYNONYMS，再查 `loadCustomSynonyms()` 自定义字典。新增 `matchSynonym()`、`tryFill()` 辅助函数。
- `entrypoints/background.ts` — `MAP_FIELDS` 处理器中 `deterministicValue()` 调用加上 `await`。
- `entrypoints/content/engine.ts` — `normalizeSignal()` 正则改为保留中文字符。`hasApplicationSurface()` 新增 6 个中文关键词（"提交申请""上传简历""求职申请""申请职位""立即申请""投递简历"）。
- `entrypoints/options/main.tsx` — 设置页增加"中文字段映射字典"区域，含表格展示、字段下拉选择、同义词输入、添加/删除按钮。数据持久化到 `chrome.storage.local`。
- `entrypoints/options/styles.css` — 新增 `.synonymList`、`.synonymRow`、`.addSynonymButton` 等样式及暗色主题适配。

## 数据映射对齐

| 用户示例 | 对应 CanonicalField | 同义词示例 |
|----------|---------------------|-----------|
| 实习经历 | `experience`（通过 `currentEmployer`/`currentTitle` 间接） | 实习经历, 实践经历, 实习, 过往实习, 工作经历, 工作经验 |
| 姓名 | `identity.firstName` | 姓名, 名字, 名, 您的名字 |
| 邮箱 | `identity.email` | 邮箱, 电子邮件, 电子邮箱, 邮件地址 |
| 公司 | `applicationDefaults.currentEmployer` | 公司, 当前公司, 现公司, 所在公司, 目前公司 |
| 期望薪资 | `applicationDefaults.desiredSalary` | 期望薪资, 期望工资, 期望薪酬, 薪资要求 |

## 验证

- `npm run compile` 通过（`tsc --noEmit`）
