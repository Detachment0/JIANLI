# 测试指南

## 启动测试服务器

```bash
# 在项目根目录执行
npx serve test -l 8080
```

浏览器打开 `http://localhost:8080/test-form.html`

## 测试步骤

### 1. 注入简历数据

点击扩展图标 → "注入简历" → 状态栏提示"简历已注入"

> 简历数据来源：`lib/resumeData.ts`（你提供的简历实例）

### 2. 一键填充

- 点击"自动填充当前页面" → 直接填充 + 弹出结果通知
- 点击"预览填充" → 弹窗展示预览 → 确认后执行填充

### 3. 查看填充结果

填充完成后，页面右下角弹出浮动通知条，展示：
- 填充率（如 72%）
- 按模块统计（基本信息 3/3、工作经历 1/3 等）
- 全部字段清单（可展开）

Popup 中底部"查看上次填充结果"按钮可查看详细报告。

### 4. 清除简历数据

点击扩展图标 → "清除简历" → 状态栏提示"简历数据已清除"

## 填充状态覆盖测试

| 字段 | 状态 | 验证方式 |
|------|------|----------|
| 自定义字段（无字典映射） | ❓ no_match | 查看通知中是否标记为"未匹配" |
| LinkedIn 主页（无数据） | ➖ no_data | 查看通知中是否标记为"无数据" |
| 签证状态（无数据） | ➖ no_data | 同上 |
| 性别（无数据） | ➖ no_data | 同上 |
| 种族（无数据） | ➖ no_data | 同上 |
| 自定义组件（div contenteditable） | ✋ custom_component | 查看通知中是否标记为"需手动操作" |
| 法律确认 checkbox | ⊘ skipped | 查看通知中是否标记为"已跳过" |

## 调试技巧

### 查看 Content Script 是否在运行

在页面中按 F12 → Console，输入：

```js
// 发送测试消息查看响应
chrome.runtime.sendMessage({ kind: "AUTOFILL_CURRENT_FORM" }, (r) => {
  console.log("填充响应:", r);
  if (chrome.runtime.lastError) console.error("错误:", chrome.runtime.lastError);
});
```

### 查看 Service Worker 日志

`edge://extensions` → 找到扩展 → 点击"Service Worker"旁的"检查视图" → Console

### 检查字段是否被识别

```js
// 在页面控制台执行
document.querySelectorAll("input, textarea, select").forEach(el => {
  console.log(el.name || el.id || el.placeholder || "(无标签)");
});
```
