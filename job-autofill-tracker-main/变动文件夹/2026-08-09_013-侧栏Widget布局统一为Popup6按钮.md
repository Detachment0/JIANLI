## 变更内容

### 1. Widget 侧栏布局重构

**文件**：`entrypoints/content/Widget.tsx`

**改动**：
- 侧栏打开后，上方显示与 Popup 一致的 6 个操作按钮（自动填充当前页面、预览填充、收起侧面板、跟踪仪表盘、注入简历、清除简历）
- 6 按钮下方为副导航 Tabs（匹配、自动填表、答案、跟踪器、资料）
- 简化 AutofillTab 为提示文本（操作引导到上方按钮）
- 添加 `actionBusy`/`actionStatus` 状态管理按钮操作反馈
- 添加 `doAction()` 和 `doPreview()` 处理函数

**文件**：`entrypoints/content/widget.css`

**改动**：
- 添加 `.jtActions`、`.jtActionBtn`、`.jtActionDivider`、`.jtActionStatus` 等样式，与 Popup 按钮视觉一致

### 布局变化

```
改动前:
  Header → DemoBadge → [pendingConfirm or Tabs → TabContent → Footer]

改动后:
  Header → DemoBadge → [pendingConfirm or 6 操作按钮 → Tabs → TabContent → Footer]
```

### Popup 与侧栏按钮对照

| Popup | 侧栏 Widget | 消息 |
|-------|-------------|------|
| 自动填充当前页面 | 自动填充当前页面 | `AUTOFILL_TAB` |
| 预览填充 | 预览填充 | `PREVIEW_FILL` |
| 打开侧面板 | 收起侧面板 | 无（关闭面板） |
| 跟踪仪表盘 | 跟踪仪表盘 | `OPEN_DASHBOARD` |
| 注入简历 | 注入简历 | `INJECT_RESUME_PROFILE` |
| 清除简历 | 清除简历 | `CLEAR_RESUME_PROFILE` |
